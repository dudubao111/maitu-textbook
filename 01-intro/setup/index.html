    1.2 学习路径与环境准备¶

    一、三步走的学习路径¶

    学编程最怕"东一榔头西一棒槌"。本章给你一条明确的主线，跟着走就不会乱：

    阶段 章节 目标 大致投入
    ① 打地基 第 1—3 章 认识竞赛、建立计算思维、学会变量与输入输出 约 8 课时
    ② 学语法 第 4—6 章 流程控制、列表字符串、函数——能写出完整程序 约 12 课时
    ③ 练算法 第 7 章 枚举、查找、排序、递推，面对真正的竞赛考点 约 8 课时
    ④ 上战场 第 8 章 + 真题 读题、建模、调试、提交，形成完整闭环 约 4 课时

    32 课时怎么排？

    假设每周 2 课时（约 90 分钟），16 周正好学完。 建议节奏是：上课听讲 + 课后把每节的"实践任务"亲手敲一遍。 只看不敲，等于没学——这是所有初学者的第一号陷阱。

    二、准备你的编程环境¶

    你有两种选择，推荐第一种，因为它更稳定、更适合长期学习。

    第 1 步：下载 Python

    访问 Python 官方网站的下载页，选择 3.10 以上的稳定版本，下载 Windows 或 macOS 安装包。 如果你的网络下载较慢，可以在国内镜像站搜索"Python 安装包镜像"加速。

    Windows 安装时的一个关键勾选

    安装界面的最下方有一个 "Add Python to PATH"（把 Python 加入环境变量）复选框， 一定要勾上。不勾的话，后面在命令行里输入 python 会提示"不是内部或外部命令"。

    第 2 步：验证安装

    打开命令行（Windows 按 Win + R，输入 cmd 回车；macOS 打开"终端"），输入：

    python --version

    如果显示类似 Python 3.12.4 的版本号，说明安装成功。

    如果提示"不是内部或外部命令"怎么办？

    说明 Python 没加入环境变量。两个解决办法： ① 重新运行安装包，选择 "Modify"，勾选 "Add Python to PATH"； ② 或者直接用 Python 自带的 IDLE（开始菜单里搜 "IDLE"），它不需要命令行。

    第 3 步：选一个写代码的地方

    工具 特点 适合谁
    IDLE Python 自带，零配置，装完就能用 刚起步，想最快写出第一行代码
    Thonny 界面极简，专为初学者设计 小学高年级、初中学生
    VS Code 功能强，插件丰富，能一直用到打比赛 有一定基础后长期使用

    建议：先用 IDLE 或 Thonny 开始，熟练后换 VS Code。

    如果暂时无法在本机安装 Python（比如用的是学校的公共电脑）， 也可以使用浏览器里的在线 Python 运行环境。

    • 优点：不用安装，打开网页就能写；
    • 缺点：需要联网、代码保存在别人服务器上、调试体验不如本机。

    关于在线环境的选择

    本教材不绑定任何具体的在线平台。你可以在搜索引擎中查找"在线 Python 运行"， 选择一个无需登录、能直接运行代码的即可。 比赛训练阶段仍然强烈建议回到本机环境，因为正式比赛无法使用网页工具。

    三、第一个程序：让计算机跟你打招呼¶

    环境装好后，我们来运行本教材的第一个完整程序。

    在 IDLE 中选择 File → New File，把下面的代码原样敲进去（不要复制，手敲一遍）：

    hello_maitu.py
    1
2
3
    # 第一个程序：让计算机向学习者打招呼
print("你好，码途！")
print("我是一名准备参加信息科技竞赛的学生。")

    保存为 hello_maitu.py，然后按 F5（或选择 Run → Run Module）运行。

    预期输出：

    你好，码途！
我是一名准备参加信息科技竞赛的学生。

    恭喜，你已经是一名"写过能运行的程序"的人了

    别看这个程序简单，它包含了编程的三个基本要素： print 是函数（让计算机做一件事），括号里的引号内容是字符串（数据）， # 开头的一行是注释（写给人看，计算机不执行）。 第 3 章会把它们逐一讲清楚。

    四、遇到报错不要慌¶

    初学阶段你会频繁看到红色的报错信息。报错是正常的，它其实是计算机在告诉你哪里出了问题。 请养成"读报错"的习惯，从最后一行往上读，那里通常写着错误类型和原因。

    常见报错（截取片段） 含义 处理办法
    SyntaxError: invalid syntax 语法错误，写错了符号 检查是否漏了引号、括号，或用了中文标点
    IndentationError 缩进错误 检查行首空格是否对齐（Python 对缩进敏感）
    NameError: name 'xxx' is not defined 用了一个没定义的名字 检查变量名是否拼错，或忘了先赋值
    TypeError 类型不匹配 比如把文字和数字直接相加，需要先转换类型

    中文标点：新手第一大坑

    Python 里的引号、括号、逗号、冒号必须用英文半角。 看起来像 “ 的是中文左引号，" 才是英文引号。 如果报 SyntaxError 又看不出问题，先检查是不是打了中文标点。 本教材所有代码中的标点都是英文半角，请照此输入。

    本章小结¶

    第 1 章 小结

    1. 竞赛只认白名单。 正规赛事必须出现在教育部《面向中小学生的全国性竞赛活动名单》里， 具有"零收费""不与升学挂钩""每学年不超过 1 次"三个特征。

    2. 有两条主线。 奥赛体系（CSP-J/S → NOI）只收 C++，有 12 周岁门槛； 信息素养 / 人工智能体系支持多种语言、面向学段更广。先定位，再投入。

    3. 语言不是障碍，但要诚实面对。 Python 是理解算法最快的入门语言， 但不能用于 CSP-J/S 提交，最终要迁移到 C++。

    4. 环境先跑通。 装好 Python（记得勾选 "Add Python to PATH"）， 跑出第一个 print 程序，就已经跨过了最难的第一步。

    5. 报错不可怕。 学会从报错信息的最后一行找出错误类型，优先检查中文标点与缩进。

    练习与参考¶

    练习 1（单选）

    下列关于教育部白名单赛事的说法，正确的是：

    A. 获奖可以作为中考加分依据 B. 主办方可以向学生收取适量报名费 C. 竞赛应坚持公益性，做到"零收费" D. 同一赛事每学年可以举办多次

    参考答案与评价要点

    答案：C

    评价要点：能准确指出 A、B、D 均违反白名单赛事的三条硬性规定。 答对得 100 分；能同时说明三条规定的具体内容，视为完全掌握。

    练习 2（判断）

    判断下列说法是否正确，并说明理由：

    1. 学习 Python 之后，可以直接用 Python 参加 CSP-J/S 认证。
    2. 广东省的学生如果学校没有信息学教练，可以自己在网上报名 CSP-J/S。
    参考答案与评价要点
    1. 错误。CSP-J/S 只接受 C++ 提交，明确不接收 Python。 评价要点：必须点出"只收 C++"这一关键事实。
    2. 错误。广东省不设个人报名，必须由学籍所在校在职在编教师审核。 评价要点：能说出"须经学籍学校教师审核"即可得满分。

    练习 3（操作）

    在自己的电脑上完成 Python 环境安装，运行本节给出的 hello_maitu.py， 并把它修改为输出你自己的姓名和所在学校年级。

    参考答案与评价要点

    参考代码：

    print("你好，码途！")
print("我是湛江某某中学初二的张三。")

    评价标准： - 环境搭建成功，能运行任何 Python 程序（40 分） - 程序输出正确、无报错（30 分） - 能主动修改内容并重新运行，理解 print 的作用（30 分）

    练习 4（思考）

    结合 1.1 竞赛地图，写一段 100 字左右的说明： 你打算走路线 A（奥赛）还是路线 B（素养 / AI）？理由是什么？

    参考答案与评价要点

    本题无唯一答案，重点看推理过程。评价要点： - 能结合自身年龄、学籍、数学基础、可投入时间做判断（50 分） - 能说出所选路线对应的语言要求（路线 A 需 C++）（30 分） - 表述清晰，不超过 150 字（20 分）
