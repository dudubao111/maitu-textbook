    8.2 提交规范与实战流程¶

    一、输入输出：竞赛和平时练习最大的区别¶

    平时练习时，我们习惯写：

    n = int(input("请输入一个整数："))    # ⚠️ 带提示语

    但在比赛中，这样写会直接零分——因为提示语 请输入一个整数： 会被算作程序的输出， 和题目要求的输出格式不符。

    竞赛铁律：程序只输出题目要求的内容

    # ❌ 错误：带了提示语
n = int(input("请输入 n："))
print("答案是", n * 2)

# ✅ 正确：干净地读，干净地写
n = int(input())
print(n * 2)

    同理，调试用的 print 必须在提交前全部删除。

    常见输入格式与对应读法¶

    题目输入格式 Python 读法
    第一行一个整数 n = int(input())
    一行多个整数（空格隔开） a, b = map(int, input().split())
    第一行 n，第二行 n 个数 n = int(input())
    nums = list(map(int, input().split()))
    多行，每行一个数 循环 int(input())
    一行字符串 s = input()

    常见输出格式¶

    题目要求 Python 写法
    输出一个整数 print(result)
    保留两位小数 print(f"{result:.2f}")
    每行输出一个数 在循环里 print(x)
    输出多个数用空格隔开 print(" ".join(map(str, nums)))
    不存在时输出 -1 用 if 判断后分别输出

    小技巧：一次性输出整个列表

    nums = [3, 7, 11]
print(" ".join(map(str, nums)))     # 输出：3 7 11
    map(str, nums) 把每个数字转成字符串，join 用空格把它们连起来。 这比写循环更简洁，且不会多出多余的换行。

    二、时间与内存限制¶

    比赛通常会给每道题设定：

    限制 常见值 含义
    时间限制 1000 ms（1 秒） 程序必须在 1 秒内跑完所有测试点
    内存限制 128 MB / 256 MB 程序运行占用的内存不能超过

    Python 会比 C++ 慢很多

    同样的算法，Python 通常比 C++ 慢 10 到 50 倍。 这意味着：一道 C++ 写 O(n²) 能过的题（n ≤ 1000），Python 可能就会超时。

    所以： - 用 Python 练习时，要更注意算法效率； - 正式参加 CSP-J/S 时，必须换用 C++（见本节第四部分）。

    三、赛前检查清单¶

    提交前，请逐条核对：

    • [ ] 删除了所有调试用的 print
    • [ ] input() 中没有提示语
    • [ ] 输出格式与题目完全一致（大小写、空格、换行、小数位数）
    • [ ] 用题目给出的样例测试过
    • [ ] 测试了边界情况（n = 1、全相同、全负数、最大值）
    • [ ] 测试了大数据，确认不会超时
    • [ ] 文件名符合要求（有些比赛要求特定文件名，如 main.py）

    养成习惯：先测样例，再测边界，最后提交

    这三步只需要一两分钟，但能避免绝大多数"冤枉分"。

    四、从 Python 迁移到 C++¶

    如果你决定走信息学奥赛路线（CSP-J/S、NOI），必须迁移到 C++。 好消息是：你已经学完了算法思想，剩下的主要是"换一门语法"。

    语法对照表¶

    Python C++ 说明
    print(x) cout << x << endl; 输出
    n = int(input()) int n; cin >> n; 读入整数
    a, b = map(int, input().split()) int a, b; cin >> a >> b; 读入两个整数
    s = input() string s; cin >> s; 读入字符串
    if a >= 60: if (a >= 60) { ... } 分支（注意括号和分号）
    for i in range(n): for (int i = 0; i < n; i++) { } 循环
    while x > 0: while (x > 0) { } 循环
    lst = [] vector<int> v; 动态数组
    lst.append(x) v.push_back(x); 追加
    len(lst) v.size() 长度
    def f(a): return a int f(int a) { return a; } 函数（需声明返回类型）

    #include <bits/stdc++.h>      // 万能头文件，包含了常用库

    int n;

    C++ 与 Python 的三个显著不同

    1. 必须写 main 函数，程序从 main 开始执行；
    2. 变量要声明类型（int n;），不能像 Python 那样直接赋值；
    3. 每行以分号 ; 结尾，大括号 {} 代替缩进表示代码块。

    建议的迁移路线¶

    阶段 任务 时间建议
    ① 语法转换 把本教材第 1—6 章的示例用 C++ 重写一遍 2—3 周
    ② 补齐 C++ 特有知识 数组、结构体、long long、指针初步 2 周
    ③ 算法重新实现 把第 7 章的枚举、查找、排序、递推用 C++ 写一遍 2 周
    ④ 真题训练 做 CSP-J 历年第一轮/第二轮真题 长期

    不要"从零开始学 C++"

    你已经有算法基础了，不要再去从头看语法教程。 最有效的方式是：拿你已经用 Python 写通的题，用 C++ 再写一遍。 在"翻译"的过程中，你会自然而然地掌握 C++ 语法。

    本章小结¶

    第 8 章 小结

    1. 五步解题流程。 读题 → 样例分析 → 建模 → 编码 → 自测提交。 手动算样例这一步绝不能省。

    2. 读题圈五类信息。 数据范围、输入格式、输出格式、特殊情况、限制条件。

    3. 调试的主力方法是打印调试。 先确认输入，再二分定位； 提交前务必删除调试语句。

    4. 五类常见错误。 答案错误（WA）、超时（TLE）、运行时错误（RE）、 格式错误（PE）、编译错误（CE）。其中格式错误最"冤"，也最容易避免。

    5. 竞赛铁律。 input() 不带提示语，print 只输出题目要求的内容， 初始值要考虑极端情况。

    6. Python 与 C++。 Python 比 C++ 慢 10—50 倍； 想走信息学奥赛，必须把已学的算法用 C++ 重写一遍，而不是从零学语法。

    练习与参考¶

    练习 1（找错）

    下面程序中，哪几行在正式比赛提交时必须修改？为什么？

    n = int(input("请输入数字个数："))
nums = list(map(int, input().split()))
print("DEBUG:", nums)
total = sum(nums)
print("总和是：", total)
    参考答案与评价要点
    1. 第 1 行去掉提示语 "请输入数字个数：" → n = int(input())
    2. 第 3 行删除调试语句
    3. 第 5 行去掉多余文字，改为 print(total)（题目若要纯数字输出）

    评价要点：三处都指出得满分（100 分）；漏一处扣 30 分。

    练习 2（输出格式）

    题目要求：输出所有满足条件的数，每行一个，共 5 个。 下面的输出方式哪一种是正确的？

    A. print(nums) （其中 nums 是长度为 5 的列表） B. print(" ".join(map(str, nums))) C. for x in nums: print(x) D. print(nums[0], nums[1], nums[2], nums[3], nums[4])

    参考答案与评价要点

    答案：C（每行一个）

    评价要点：能区分"每行一个"与"一行多个"即得满分。 B 和 D 都是"一行多个"，A 会输出列表的方括号和引号，均不符合要求。

    练习 3（调试）

    下面的程序想输出 1 到 n 的和，但在 n = 0 时会输出 0， 题目要求 n = 0 时输出 0（正确）。但 n = 1 时输出 0（错误）。 请找出问题。

    n = int(input())
total = 0
for i in range(1, n):
    total += i
print(total)
    参考答案与评价要点

    问题：range(1, n) 是左闭右开，不包含 n。 n = 1 时循环一次都不执行，total 保持 0。

    改正：for i in range(1, n + 1):

    评价要点：能指出"左闭右开导致漏掉 n"即得满分。

    练习 4（迁移）

    把下面的 Python 程序改写成 C++ 程序：读入两个整数，输出它们的和。

    a, b = map(int, input().split())
print(a + b)
    参考答案与评价要点 
    #include <bits/stdc++.h>
using namespace std;

int main() {
    int a, b;
    cin >> a >> b;
    cout << a + b << endl;
    return 0;
}

    评价要点：能正确使用 cin / cout（40 分）； 包含头文件与 main 函数（40 分）；语法正确、分号不遗漏（20 分）。

    你已经走完了这本书

    从"什么是竞赛"到"能独立解题并提交"，八章下来，你已经具备了入门级竞赛选手的全部基础。 接下来最重要的事只有一件：去做题。

    推荐的自练顺序： ① 把每章的"实践任务"再手写一遍 → ② 找历年真题从最简单的开始 → ③ 每做错一题就记下来。

    祝你在竞赛中玩得开心，也学得扎实。
