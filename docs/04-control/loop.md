# 4.2 循环结构：让程序会重复

## 一、为什么需要循环

需求：**求 1 到 100 所有整数的和。**

不用循环，你得写 100 行…… 用循环，只要 4 行：

```python
total = 0
for i in range(1, 101):
    total = total + i
print(total)
```

**运行结果：**

```text
5050
```

## 二、`for` 循环：知道要重复多少次

`for` 循环适合"**次数已知**"的场景。

### 语法结构

```python
for 变量 in 可迭代对象:
    循环体（要重复执行的代码，注意缩进）
```

最常用的是配合 `range()`：

```python
for i in range(1, 6):
    print(i)
```

**运行结果：**

```text
1
2
3
4
5
```

!!! danger "range 是"左闭右开"，这是最大的坑"
    `range(1, 6)` 生成的是 **1, 2, 3, 4, 5**，**不包含 6**！

    | 写法 | 生成的数 | 个数 |
    |---|---|---|
    | `range(5)` | 0,1,2,3,4 | 5 个 |
    | `range(1, 6)` | 1,2,3,4,5 | 5 个 |
    | `range(0, 10, 2)` | 0,2,4,6,8 | 5 个（步长 2） |
    | `range(5, 0, -1)` | 5,4,3,2,1 | 5 个（倒着数） |

    `range(start, stop, step)` 中：**包含 start，不包含 stop**。
    想打印 1 到 100，要写 `range(1, 101)`。

### 三种常见用法

```python
# 用法 1：只要次数，不关心变量值
for _ in range(3):
    print("你好")

# 用法 2：用循环变量
for i in range(1, 4):
    print(f"第 {i} 次")

# 用法 3：遍历字符串的每个字符
for ch in "码途":
    print(ch)
```

**运行结果：**

```text
你好
你好
你好
第 1 次
第 2 次
第 3 次
码
途
```

## 三、`while` 循环：条件满足就一直做

`while` 适合"**次数未知，只知道什么时候停**"的场景。

```python
count = 1
while count <= 5:
    print(count)
    count = count + 1        # ⚠️ 别忘了这一行！
```

**运行结果：**

```text
1
2
3
4
5
```

!!! danger "死循环：忘了改变量就出不去了"
    如果删掉 `count = count + 1` 这一行，`count` 永远是 1，
    `count <= 5` 永远为真，程序会**无限循环**，屏幕上疯狂刷 `1`。

    遇到这种情况：**按 `Ctrl + C` 强制停止程序。**

    **写 `while` 时，请养成习惯：先问自己"什么情况下循环会停？"**

### `for` 还是 `while`？

| 场景 | 推荐 | 例子 |
|---|---|---|
| 次数已知 | `for` | 求 1 到 100 的和、打印 10 次 |
| 次数未知，靠条件停 | `while` | 猜数字游戏、不断读入直到输入 0 |

## 四、`break` 与 `continue`

| 关键字 | 作用 | 记忆口诀 |
|---|---|---|
| `break` | **立刻跳出**整个循环 | "不干了，走人" |
| `continue` | **跳过本次**，直接进入下一次 | "这次算了，下一个" |

```python
# break 示例：找到第一个能被 7 整除的数就停
for i in range(1, 100):
    if i % 7 == 0:
        print(f"第一个能被 7 整除的数是 {i}")
        break
```

**运行结果：**

```text
第一个能被 7 整除的数是 7
```

```python
# continue 示例：只打印奇数
for i in range(1, 11):
    if i % 2 == 0:
        continue          # 偶数就跳过本次，不打印
    print(i)
```

**运行结果：**

```text
1
3
5
7
9
```

## 五、嵌套循环

循环里面还能有循环。最经典的例子是**九九乘法表**：

```python title="multiplication_table.py" linenums="1"
for i in range(1, 10):          # 外层：控制行（1 到 9）
    for j in range(1, i + 1):   # 内层：控制列（1 到 i）
        print(f"{j}×{i}={i*j}", end="\t")
    print()                     # 每行结束后换行
```

**部分运行结果：**

```text
1×1=1
1×2=2	2×2=4
1×3=3	2×3=6	3×3=9
...
```

!!! tip "读懂嵌套循环的诀窍"
    **外层的循环变量 `i` 变化一次，内层就要完整跑一遍。**
    上例中，`i = 1` 时内层跑 1 次；`i = 2` 时内层跑 2 次……所以每一行的列数在递增。
    `end="\t"` 表示输出后加一个制表符（不换行），`print()` 空参数表示只换行。

## 六、代码实践：判断素数

> **问题**：输入一个大于 1 的整数，判断它是否为素数（质数）。
> **素数的定义**：只能被 1 和它本身整除的数。

```python title="is_prime.py" linenums="1"
n = int(input("请输入一个大于 1 的整数："))

is_prime = True              # 先假设它是素数
for i in range(2, n):        # 检查 2 到 n-1 有没有能整除 n 的数
    if n % i == 0:
        is_prime = False     # 找到了因子，说明不是素数
        break                # 不用再检查了

if is_prime:
    print(f"{n} 是素数")
else:
    print(f"{n} 不是素数")
```

**运行结果：**

```text
输入 17 → 17 是素数
输入 15 → 15 不是素数
输入 2  → 2 是素数
```

!!! success "这个程序的三个要点"
    1. **先假设，再推翻**：用一个布尔变量 `is_prime` 表示结论，是编程常用套路；
    2. **`break` 提高效率**：一旦找到因子就没必要继续检查；
    3. **`range(2, n)` 不包含 n**：这正是我们想要的，因为不需要检查 n 本身。

    **进阶思考**：其实只需要检查到 `n` 的平方根就够了。为什么？
    （提示：如果 `n = a × b`，那么 a 和 b 中必有一个 ≤ √n）

## 七、案例分析：猜数字游戏（简版）

> **问题**：程序预设一个数字，让用户反复猜，直到猜对为止。

```python title="guess_number.py" linenums="1"
secret = 42
guess = -1

while guess != secret:
    guess = int(input("猜一个 1 到 100 的数字："))
    if guess > secret:
        print("太大了")
    elif guess < secret:
        print("太小了")

print("恭喜，猜对了！")
```

**运行示例：**

```text
猜一个 1 到 100 的数字：50
太大了
猜一个 1 到 100 的数字：20
太小了
猜一个 1 到 100 的数字：42
恭喜，猜对了！
```

!!! note "为什么 `guess` 要初始化成 -1？"
    因为 `while` 循环开始前要先判断 `guess != secret`。
    如果 `guess` 还没定义就使用，程序会报 `NameError`。
    **给循环变量一个"肯定不等于目标"的初始值**，是 `while` 的常见写法。

## 本章小结

!!! abstract "第 4 章 小结"
    **1. 三种基本结构**：顺序、分支、循环。三种组合起来可以表达任何程序逻辑。

    **2. 分支要点。** `if / elif / else`；
    **条件是"从严格到宽松"排列**，顺序写反会得到错误结果；
    `=` 是赋值，`==` 才是等于。

    **3. 缩进即语法。** Python 用 4 个空格表示代码块的从属关系，缩进错逻辑就错。

    **4. 循环要点。** 次数已知用 `for`，次数未知用 `while`；
    **`range(start, stop)` 左闭右开**，所以要打印 1 到 100 得写 `range(1, 101)`。

    **5. `while` 必须有"出口"。** 循环体内一定要有能改变条件的语句，
    否则会死循环（用 `Ctrl + C` 停止）。

    **6. `break` 跳出，`continue` 跳过。** 它们是循环的两种"控制阀"。

    **7. 逻辑运算符。** `and`（都真才真）、`or`（一真即真）、`not`（取反）；
    Python 支持 `60 <= score <= 100` 这种连续比较。

## 练习与参考

!!! question "练习 1（读程序）"
    下面程序会输出什么？

    ```python
    total = 0
    for i in range(1, 5):
        total += i
    print(total)
    ```

    ??? success "参考答案与评价要点"
        **输出 `10`。** `range(1, 5)` 生成 1、2、3、4，累加得 10。

        评价要点：答对得 100 分。若答 `15`，说明误以为 `range` 包含 5，需回看左闭右开规则。

!!! question "练习 2（读程序）"
    下面程序会输出什么？为什么？

    ```python
    for i in range(1, 10):
        if i == 5:
            break
        print(i)
    ```

    ??? success "参考答案与评价要点"
        **输出 1、2、3、4**（各占一行）。
        当 `i` 等于 5 时执行 `break`，**当前这次循环直接结束，连 `print` 都不会执行**，
        整个循环也随之终止。

        评价要点：能说出"break 立即终止整个循环"即得满分。

!!! question "练习 3（编程）"
    编写程序，计算 1 到 100 之间所有**偶数**的和。

    ??? success "参考答案与评价要点"

        ```python
        total = 0
        for i in range(1, 101):
            if i % 2 == 0:
                total += i
        print(total)
        ```

        结果：`2550`

        进阶写法（步长为 2）：
        ```python
        total = 0
        for i in range(2, 101, 2):
            total += i
        print(total)
        ```

        评价要点：结果正确（60 分）；能写出第二种更简洁的写法（20 分）；
        代码规范、有注释（20 分）。

!!! question "练习 4（编程）"
    编写程序，输入一个整数 `n`，输出它的**阶乘** `n!`
    （`n! = 1 × 2 × 3 × ... × n`，规定 `0! = 1`）。

    ??? success "参考答案与评价要点"

        ```python
        n = int(input("请输入一个整数："))
        result = 1
        for i in range(1, n + 1):
            result *= i
        print(f"{n}! = {result}")
        ```

        输入 `5` → 输出 `5! = 120`。

        评价要点：`result` 初始值必须是 `1`（不是 0！）（40 分）；
        循环范围正确（30 分）；结果正确（30 分）。

!!! question "练习 5（综合）"
    编写程序，输出 1 到 100 之间**所有既是 3 的倍数又是 5 的倍数**的整数。

    ??? success "参考答案与评价要点"

        ```python
        for i in range(1, 101):
            if i % 3 == 0 and i % 5 == 0:
                print(i)
        ```

        结果：15、30、45、60、75、90

        评价要点：能正确使用 `and` 连接两个条件（50 分）；
        循环范围正确（30 分）；结果完整（20 分）。
