# 第 4 章 流程控制

!!! abstract "本章导学"
    到目前为止，你写的程序都是"从上到下，一条路走到底"。但真实的问题需要程序**做判断**
    （成绩及格了吗？）、**重复做事**（把 45 个分数加起来）。这一章就是教程序"拐弯"和"绕圈"，
    它是**全书最重要的一章**——竞赛里几乎所有题目都离不开分支和循环。

## 学习目标

学完本章，你应当能够：

1. **使用** `if / elif / else` 写出多分支判断，并能正确使用比较运算符；
2. **区分** `for` 循环与 `while` 循环的适用场景；
3. **使用** `range()` 控制循环次数，理解"左闭右开"的区间规则；
4. **嵌套** 使用分支与循环，解决稍复杂的实际问题。

## 本章知识地图

| 小节 | 核心问题 | 关键点 |
|---|---|---|
| **4.1 分支结构：让程序会选择** | 怎么让程序"看情况办事"？ | `if / elif / else`、比较运算符、`and/or/not` |
| **4.2 循环结构：让程序会重复** | 怎么让程序"重复干活"？ | `for`、`while`、`range()`、`break/continue` |
| ↘ 本章小结与练习 | 掌握了吗？ | 自测清单 + 5 道练习（含参考答案） |

## 先看一眼全貌

```text
顺序结构（第 3 章）          分支结构（4.1）              循环结构（4.2）
   做 A                         是 ──► 做 A                做 A
   做 B                      ？          └─► 做 B          回到 A 再做
   做 C                         否 ──► 做 C                    │
                                                              否
                                                          ？ ──┴──► 做 B
                                                              是
```

**三种结构组合起来，就能写出任何程序。** 这句话不是夸张，而是计算机科学的基本结论。
