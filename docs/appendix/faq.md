# 附录 B · 常见问题

本附录收录学习过程中最常遇到的问题。建议先在这里找找答案，再考虑求助。

## 一、环境与安装

??? question "输入 `python` 提示"不是内部或外部命令"，怎么办？"
    说明安装 Python 时**没有勾选 "Add Python to PATH"**。三种解决办法：

    1. **最省事**：直接用开始菜单里的 **IDLE**，它不需要命令行；
    2. **推荐**：重新运行 Python 安装包，选 "Modify"，勾选 "Add Python to PATH"；
    3. **临时**：在命令行里输入 Python 的完整安装路径，例如
       `C:\Users\你的用户名\AppData\Local\Programs\Python\Python312\python.exe`。

??? question "下载 Python 太慢，有别的办法吗？"
    可以。在搜索引擎里搜索"Python 国内镜像下载"，从国内镜像站获取安装包通常快很多。
    注意**下载与你的系统匹配的版本**（Windows 64 位 / macOS）。

??? question "该用 IDLE、Thonny 还是 VS Code？"
    - **刚开始**：用 IDLE 或 Thonny，零配置，能立刻写代码；
    - **熟练后**：换 VS Code，功能强、能一直用到打比赛。

    不必纠结，**任何能运行 Python 的工具都行**。工具不是学习的关键。

## 二、语法与报错

??? question "什么是中文标点问题？为什么老是报 SyntaxError？"
    Python 里的引号、括号、逗号、冒号**必须是英文半角**。

    | 错误（中文） | 正确（英文） |
    |---|---|
    | `“你好”` | `"你好"` |
    | `（1+2）` | `(1+2)` |
    | `,` `，` | `,` |
    | `：` | `:` |

    **遇到 `SyntaxError` 又看不出问题时，第一件事就是检查有没有打成中文标点。**

??? question "为什么 `input()` 读进来的数字不能直接相加？"
    因为 **`input()` 永远返回字符串**。用户输入 `5`，拿到的是文字 `"5"`，
    不是数字 `5`。

    ```python
    a = int(input())      # ✅ 立刻转换
    ```

    详见 [3.2 输入输出与类型转换](../03-basics/io.md)。

??? question "`print` 和 `return` 有什么区别？"
    - `print`：把内容**显示在屏幕上**，之后没法再用这个值；
    - `return`：把结果**交回给调用者**，可以继续参与运算。

    详见 [6.1 函数：把代码打包](../06-func/define.md)。

??? question "为什么 `x = lst.sort()` 之后 `x` 是 `None`？"
    因为 `sort()` 是**原地排序**，它直接修改原列表，**没有返回值**。

    ```python
    lst.sort()              # ✅ 直接排，不要赋值
    x = sorted(lst)         # ✅ 想要新列表就用 sorted
    ```

??? question "缩进到底要几个空格？Tab 可以吗？"
    官方推荐 **4 个空格**。**不要 Tab 和空格混用**，否则会报
    `TabError: inconsistent use of tabs and spaces in indentation`。
    大多数编辑器可以设置"按 Tab 键自动插入 4 个空格"，建议开启。

## 三、逻辑与调试

??? question "程序没有报错，但结果不对，怎么查？"
    按顺序排查：

    1. **先确认输入对不对**——在开头 `print` 一下读进来的数据；
    2. **二分定位**——在程序中间 `print`，判断错误在前半段还是后半段；
    3. **小数据手推**——用 n = 1、2 手动算一遍，和程序对照；
    4. **检查边界**——全负数、全相同、只有一个元素，是否都正确。

    详见 [8.1 读题、建模与调试](../08-practice/debug.md)。

??? question "为什么我的循环停不下来？"
    多半是 `while` 循环里**忘了改变判断条件涉及的量**：

    ```python
    i = 0
    while i < 10:
        print(i)        # ❌ 忘了 i = i + 1，死循环
    ```

    **写 `while` 时先问自己："什么情况下循环会停？"**
    遇到死循环按 `Ctrl + C` 强制停止。

??? question "`IndexError: list index out of range` 是什么意思？"
    索引越界。列表只有 n 个元素时，合法索引是 `0` 到 `n-1`。

    ```python
    lst = [1, 2, 3]
    print(lst[3])       # ❌ 越界，最大索引是 2
    print(lst[len(lst) - 1])   # ✅ 最后一个元素
    ```

## 四、竞赛相关

??? question "我学 Python，能直接参加 CSP-J/S 吗？"
    **不能。** CSP-J/S 与 NOI **只接受 C++ 提交**，明确不接收 Python。

    本教材用 Python 是为了让你更快理解算法。学完第 7 章后，
    请参考 [8.2 提交规范与实战流程](../08-practice/submit.md) 的迁移路线转向 C++。

??? question "竞赛获奖能加分吗？"
    **不能。** 教育部明确规定：面向中小学生的竞赛结果
    **不得作为中小学招生入学的依据，也不得作为高考加分项目**。

    任何声称"包获奖""获奖保送"的机构都涉嫌违规，请提高警惕。

??? question "怎么判断一个比赛是不是正规的？"
    到教育部官网搜索《面向中小学生的全国性竞赛活动名单》，看它是否在名单中。
    正规赛事有三个特征：**零收费、不与升学挂钩、每学年不超过 1 次**。

    详见 [1.1 竞赛地图](../01-intro/map.md)。

??? question "广东省报名 CSP-J/S 有什么特别要注意的？"
    广东省**不设个人报名**：认证者必须持有广东省内学校有效学籍，
    且**必须由学籍所在校的在职在编教师**审核，
    校外培训机构一律不得注册和审核相关事务。

    **所以第一步是去问你的信息技术老师，而不是买书或报班。**

??? question "为什么同样的算法，我的 Python 程序超时，别人的 C++ 能过？"
    Python 通常比 C++ **慢 10 到 50 倍**。同一个算法，C++ 能过的时间限制，
    Python 可能就超时。

    用 Python 练习时的应对办法：
    ① 优先选择复杂度更低的算法；② 避免不必要的嵌套循环；
    ③ 尽量使用内置函数（如 `sum`、`max`、`sorted`），它们用 C 实现，比自己写的循环快得多。

## 五、学习建议

??? question "看不懂后面的内容，是应该回去重学还是继续往下读？"
    **建议先往下读，但要回头补。**

    第 1—3 章是地基，必须真正掌握；
    第 4 章之后的内容会反复用到前面，所以**遇到不懂的地方先记下来，
    继续往后读，等学完一章再回头统一解决**，效率比卡在原地高。

??? question "只看书不写代码，可以吗？"
    **不可以。** 编程是"手上的功夫"，看懂和自己能写出来之间隔着很远的距离。

    **每节的"实践任务"必须亲手敲一遍**，这是本教材唯一的学习要求。
