# 附录 D · 拓展阅读

本附录列出继续学习会用到的资源，并标注**用途**与**适用阶段**。
外部链接可能随网站调整而变化，若失效请通过搜索引擎按名称查找。

!!! warning "关于外部链接"
    以下链接均为**官方或长期稳定**的资源站点，仅用于学习。
    请以官方网站的**最新通知**为准，尤其是竞赛报名时间与规则。

## 一、竞赛官方渠道（必看）

| 资源 | 链接 | 用途 | 适用阶段 |
|---|---|---|---|
| **NOI 官方网站** | [www.noi.cn](https://www.noi.cn/) | 信息学奥赛官方通知、各省新闻、报名流程 | 决定走奥赛路线后 |
| **CSP-J/S 报名系统** | [cspsjtest.noi.cn](https://cspsjtest.noi.cn/) | CSP-J/S 注册与报名（往年账号失效，需重新注册） | 准备报名时 |
| **教育部官网** | [www.moe.gov.cn](https://www.moe.gov.cn/) | 查询《面向中小学生的全国性竞赛活动名单》 | 判断比赛是否正规 |

!!! tip "怎么用这几个网站"
    1. **教育部官网**：确认比赛是否在"白名单"里；
    2. **NOI 官网**：看具体赛事的报名时间、认证流程、本省政策；
    3. **CSP 报名系统**：实际报名、下载准考证、查成绩。

## 二、Python 学习资源

| 资源 | 链接 | 用途 | 适用阶段 |
|---|---|---|---|
| **Python 官方中文文档** | [docs.python.org/zh-cn](https://docs.python.org/zh-cn/) | 查询函数、方法的权威说明 | 全书通用 |
| **Python 官方教程（中文）** | [docs.python.org/zh-cn/3/tutorial](https://docs.python.org/zh-cn/3/tutorial/) | 系统性补充语法细节 | 第 3—6 章参考 |
| **菜鸟教程 Python3** | [runoob.com/python3](https://www.runoob.com/python3/python3-tutorial.html) | 中文速查，适合当"字典"用 | 全书通用 |

!!! note "怎么查资料最有效率"
    不要"从头读一遍文档"。正确的用法是：

    - 忘了 `split()` 怎么用 → **直接搜"python str split"**；
    - 不理解某个报错 → **把报错信息的最后一行原样搜索**。

    **带着问题查，比系统阅读快十倍。**

## 三、算法与练习平台

| 资源 | 说明 | 适用阶段 |
|---|---|---|
| **洛谷（Luogu）** | 国内知名的算法练习平台，有大量适合入门者的题目与题解 | 第 7 章之后 |
| **LeetCode（力扣）** | 题目分级清晰，适合练"算法题手感" | 有一定基础后 |
| **OI Wiki** | 信息学竞赛知识汇总，覆盖从入门到进阶的算法 | 长期参考 |
| **力扣 / 洛谷的"新手村"** | 专为初学者设计的入门题单 | 学完第 4 章即可开始 |

!!! tip "刷题的正确姿势"
    1. **从最简单的开始**，不要一上来就挑难题；
    2. **每题限时 30 分钟**，超时就去看题解，然后**合上题解自己重写一遍**；
    3. **建一个错题本**，记录"卡在哪里、为什么卡"，比刷题数量重要得多。

## 四、从 Python 到 C++

| 资源 | 说明 | 适用阶段 |
|---|---|---|
| **C++ 官方参考（cppreference）** | C++ 标准库的权威查询站点 | 迁移后长期使用 |
| **各类 C++ 入门教程** | 搜索"C++ 基础语法 教程"即可，内容大同小异 | 迁移阶段 |
| **NOI 官网的历年试题** | 用真题检验自己的 C++ 实现能力 | 迁移完成后 |

!!! success "迁移的最优路径"
    **不要从零学 C++ 语法。** 正确做法是：

    1. 打开本教材第 3—7 章的任意一个 Python 程序；
    2. 对照 [8.2 节的语法对照表](../08-practice/submit.md)，用 C++ 重写它；
    3. 编译运行，直到输出完全一致。

    这样"翻译"20—30 个程序后，C++ 的基本语法你就掌握了。

## 五、给教师与家长的提示

!!! note "如果孩子在准备竞赛"
    1. **先确认赛道**：是走奥赛（C++）还是素养/人工智能类（多语言）？两者准备方式差别很大；
    2. **核实比赛正规性**：到教育部官网查白名单，任何收费比赛都要警惕；
    3. **不要相信"获奖保送"**：教育部明确规定竞赛结果不与招生入学挂钩；
    4. **关注学习过程而非奖项**：计算思维的养成比一张证书更有长期价值；
    5. **广东省家长特别注意**：CSP-J/S 全省不设个人报名，需通过学籍学校在职教师审核，
       请提前与学校信息技术教师沟通。

## 学习建议总结

!!! abstract "最后三条建议"
    **1. 动手 > 阅读。** 每节的实践任务必须亲手敲一遍，这是本教材唯一的学习要求。

    **2. 错题 > 题量。** 一道题彻底搞懂，胜过十道题囫囵刷过。

    **3. 坚持 > 强度。** 每周稳定投入 4 小时，坚持一个学期，效果远好于假期突击一周。

    祝你在信息科技的世界里，走得又稳又远。
