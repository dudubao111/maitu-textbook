# 第 8 章 竞赛实战与提交规范

!!! abstract "本章导学"
    前七章你学了语法和算法，但"会做题"和"会比赛"是两回事。比赛有严格的时间、格式和规则，
    一道题可能因为**少读了一个条件**、**输出多了一个空格**而从满分变成零分。
    这一章把"从拿到题目到提交答案"的完整流程讲清楚，并给出**从 Python 迁移到 C++** 的路线图。

## 学习目标

学完本章，你应当能够：

1. **按标准流程** 读题、提取信息、建立模型、编码、自测；
2. **使用** 打印调试法与边界测试定位错误；
3. **识别** 竞赛中五种常见错误类型（答案错误、超时、运行时错误、格式错误、编译错误）；
4. **遵守** 竞赛的输入输出、文件命名与提交规范；
5. **说出** 从 Python 转向 C++ 需要补的知识点与练习路线。

## 一个真实的"惨案"

!!! failure "少看了一个条件，满分变零分"
    题目要求：**"输出所有满足条件的数，每行一个。"**

    同学小王的程序算得完全正确，但他写成了：

    ```python
    print(result)      # 把 5 个数输出在同一行，用空格隔开
    ```

    而正确输出应该是：

    ```text
    3
    7
    11
    19
    23
    ```

    **算法满分，格式零分。** 这就是为什么要专门用一章讲"实战与规范"。
