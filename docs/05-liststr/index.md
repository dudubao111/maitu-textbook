# 第 5 章 列表与字符串处理

!!! abstract "本章导学"
    前四章你学的变量，一个盒子只能装一个数据。可现实中的问题往往要处理**一批**数据——
    45 个分数、100 个数字、一整段文字。这一章教你两个"数据容器"：**列表**（装一批同类数据）
    和**字符串的处理方法**（处理文本）。它们是竞赛题里出现频率最高的两种数据形式。

## 学习目标

学完本章，你应当能够：

1. **创建和访问** 列表，理解索引从 0 开始、支持负数索引与切片；
2. **使用** 列表的常用操作：`append`、`insert`、`remove`、`pop`、`len`、`sort`；
3. **遍历** 列表，并用列表完成"找最大值""求和""筛选"等常见任务；
4. **使用** 常用字符串方法：`len`、`upper`、`lower`、`split`、`join`、`strip`、`replace`；
5. **判断** 什么时候该用列表、什么时候该用字符串。

## 一个直观的对比

| 需求 | 用变量（第 3 章） | 用列表（本章） |
|---|---|---|
| 存 3 个分数 | `s1, s2, s3 = 88, 92, 85` | `scores = [88, 92, 85]` |
| 存 45 个分数 | 😱 写 45 个变量 | `scores = [...]` 一行搞定 |
| 求最大值 | 一堆 `if` 比较 | `max(scores)` |

**数据一多，列表的优势立刻显现。**
