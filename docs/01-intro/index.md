# 第 1 章 走进信息科技竞赛

!!! abstract "本章导学"
    你可能听过"信息学奥赛""编程比赛"这些词，但它们到底指什么？谁可以参加？
    需要提前准备什么？这一章先不写代码，而是帮你把"地图"看清楚——
    知道有哪些比赛、它们分别考什么、哪一条路适合现在的你。

## 学习目标

学完本章，你应当能够：

1. **说出** 教育部白名单中与信息科技相关的至少 3 个竞赛名称及其面向学段；
2. **区分** "信息学奥赛体系（CSP-J/S、NOI）"与"信息素养 / 人工智能类赛事"两条路线；
3. **判断** 自己当前符合哪类比赛的报名条件（尤其是年龄、学籍、语言要求）；
4. **搭好** 一个可以写 Python 的编程环境，并成功运行第一个程序。

## 开始之前：先破除三个误解

!!! failure "误解 1：学编程就是为了比赛拿奖"
    比赛只是"检验学习成果"的一种方式。中小学阶段学编程真正的收获是**计算思维**——
    把复杂问题拆开、找到规律、用清晰的步骤解决它。这种能力在数学、物理甚至写作文时都用得上。

!!! failure "误解 2：竞赛获奖可以加分、可以被名校录取"
    教育部明确规定：面向中小学生的竞赛**不得作为中小学招生入学的依据，也不得作为高考加分项目**。
    任何声称"包获奖""获奖保送"的机构都在违规。请务必以教育部和主办方官方通知为准。

!!! failure "误解 3：必须从小学一年级开始学，晚了就来不及"
    不是。CSP-J/S 有"满 12 周岁"的硬性门槛，太早反而报不了名。
    初中开始系统学、高中冲刺，是完全正常的节奏。
