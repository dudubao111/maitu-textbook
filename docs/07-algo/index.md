# 第 7 章 基础算法入门

!!! abstract "本章导学"
    前面六章你学会了 Python 的基本语法。从这一章开始，你正式进入**算法**的世界。
    所谓算法，就是"解决问题的具体方法"——同一道题，笨办法能做，巧办法也能做，
    差别在于**效率**。本章介绍四把入门级武器：**枚举、查找、排序、递推**。
    掌握它们，你就能解决大部分入门竞赛题。

## 学习目标

学完本章，你应当能够：

1. **使用枚举法** 系统地遍历所有可能，并理解"何时该优化枚举范围"；
2. **实现** 顺序查找与二分查找，并说明二分查找为什么要求数据有序；
3. **实现** 冒泡排序与选择排序，理解"排序是一切查找的前提之一"；
4. **使用递推** 求解数列类问题，用贪心策略解决部分最优化问题；
5. **比较** 不同算法在同一问题上的效率差异。

## 一个重要观念：算法的"效率"

同一道题，不同算法可能差出**成千上万倍**的时间。举个例子：

| 问题 | 笨办法 | 巧办法 |
|---|---|---|
| 在 100 万个有序数字中找一个数 | 顺序查找：最多比 100 万次 | 二分查找：最多比 20 次 |
| 求 1 到 100 的和 | 循环累加 100 次 | 公式 `n(n+1)/2`：1 次 |

!!! info "什么是"时间复杂度"？"
    它粗略衡量"数据量变大时，运算次数增长得有多快"。

    | 复杂度 | 通俗理解 | 例子 |
    |---|---|---|
    | **O(1)** | 和数据量无关，一步到位 | 公式计算、索引取值 |
    | **O(n)** | 数据翻倍，时间翻倍 | 一次遍历、顺序查找 |
    | **O(n²)** | 数据翻倍，时间变 4 倍 | 双重循环、冒泡排序 |
    | **O(log n)** | 数据翻倍，只多一步 | 二分查找 |

    竞赛题目通常会给出数据范围（如 `n ≤ 1000`），
    **根据范围反推"允许用什么复杂度的算法"**，是选手的基本功。
