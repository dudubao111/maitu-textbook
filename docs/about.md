# 关于本项目

**码途 · 中小学信息科技竞赛数字教材**是一个面向中小学信息科技竞赛学习与教学的**纯静态数字教材平台**。
它没有后端、不需要登录、不依赖数据库，全部内容以 Markdown 编写，由 MkDocs 构建为可离线浏览的网页。

---

## 一、项目缘起

本项目源于一次课程实验的设计任务，出发点是想解决中小学信息科技竞赛学习中真实存在的三个问题：

!!! note "为什么需要这样一本教材"
    **1. 竞赛信息分散且真伪混杂。**
    网上能搜到的赛事信息大量是机构营销内容，家长和学生很难判断哪些比赛是正规的、自己符不符合报名条件。

    **2. 现有入门教材的读者定位错位。**
    市面上的算法书大多写给大学生或竞赛选手，动不动就是时间复杂度证明；而面向中小学的编程书又常常只讲语法，不碰算法。
    中间这一段——**"会用基本语法之后，怎么开始面对真正的竞赛题"**——恰好是缺口。

    **3. 教师缺少能直接取用的讲义。**
    信息技术教师开竞赛社团时，往往要自己从零攒课件。如果有一份结构完整、任务可布置、答案可对照的现成材料，备课成本会低很多。

---

## 二、教材定位与适用对象

### 定位：用 Python 学算法思维

本教材使用 **Python** 作为教学语言，理由是它语法接近自然语言、上手最快，且是中信息科技新课标的主要教学语言。

但必须如实说明一件事：

!!! warning "关于参赛语言的必要澄清"
    信息学奥赛体系（**CSP-J/S、NOI**）**只接受 C++ 提交，不接受 Python**。
    因此本教材的定位是 **"用 Python 学会算法思维与编程方法"**，而不是"用 Python 直接参赛"。
    学完第 7 章后，可以按 [第 8 章 · 提交规范与实战流程](08-practice/submit.md) 给出的语法对照表与迁移路线，
    用较低的成本转到 C++ 去参加 CSP-J/S。

### 适用对象：难度是分层的

| 章节 | 难度 | 适合谁 |
|---|---|---|
| 第 1—3 章 | 入门 | 小学高年级及以上，具备基本打字与文件操作能力即可 |
| 第 4—6 章 | 进阶 | 建议初中及以上。嵌套循环与递归需要一定的抽象思维能力 |
| 第 7—8 章 | 竞赛向 | 建议初中高年级及以上，或已完整学完前 6 章的学生 |

主要读者是**初中学生**（零基础或刚接触编程）；**小学高年级学生可以跟读前 3 章**；
同时也适合**信息技术教师**作为竞赛课教材或社团讲义直接使用。

## 三、内容编写原则

| 原则 | 具体做法 |
|---|---|
| **原创** | 全部章节正文、代码示例、图示与名称均为独立编写，未复制任何现有教材的原文或品牌标识 |
| **可运行** | 所有标注"可运行"的代码都是**完整程序**，复制到 Python 环境即可执行，不含伪代码 |
| **循序渐进** | 每章只引入必要的新概念，新知识都能在前一章找到落点；第 4 章起反复回用前面学过的内容 |
| **任务驱动** | 每节配 2 个编号实践任务，每个任务都写明输入要求、操作要求、预期结果与评价标准 |
| **就近反馈** | 练习紧跟正文，参考答案集中放在 [附录 C](appendix/answers.md)，方便自评与教师批改 |
| **诚实** | 竞赛政策、语言限制、难度分布等关键信息如实标注，不夸大也不含糊 |

每章统一采用同一套结构，便于教师按课时切分：

```
学习目标 → 知识讲解 → 案例分析 → 代码实践 → 本章小结 → 练习与参考
```

## 五、技术实现

本项目刻意选择轻量方案，不引入后端、数据库、用户系统与独立前端框架：

| 技术 | 作用 |
|---|---|
| **MkDocs** | 静态站点生成器，把 Markdown 编译成 HTML |
| **Material for MkDocs** | 主题，提供导航、搜索、代码高亮、提示组件与响应式布局 |
| **Markdown** | 教材正文源码，纯文本、易维护、便于版本管理 |
| **Python** | 教材示例代码语言 |
| **Git** | 版本管理，记录内容迭代 |

本地运行与构建：

```bash
# 安装依赖（国内建议加镜像源）
.venv/Scripts/python.exe -m pip install -r requirements.txt -i https://mirrors.aliyun.com/pypi/simple

# 本地预览：浏览器打开 http://127.0.0.1:8000
.venv/Scripts/python.exe -m mkdocs serve

# 构建静态站点，产物在 site/ 目录
.venv/Scripts/python.exe -m mkdocs build
```

完整的目录结构与部署说明见项目根目录的 `README.md`。

## 六、反馈与改进

本项目目前处于**课程实验原型**阶段，仍在迭代中。如果你发现以下问题，欢迎反馈：

- 正文表述不清或存在错误
- 代码示例无法运行，或运行结果与文中不符
- 实践任务的评价标准不够明确
- 竞赛政策信息已经过时

课程实验期间，请通过**任课教师**转达意见；正式发布后会在项目仓库中开放 Issue 入口。
