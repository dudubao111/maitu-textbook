# 3.2 输入输出与类型转换

## 一、输出：`print()`

`print()` 是最常用的输出函数，它有三种常见用法。

### 用法 1：一次输出多项（用逗号隔开）

```python
name = "小明"
score = 92
print("姓名：", name, "，成绩：", score)
```

**运行结果：**

```text
姓名： 小明 ，成绩： 92
```

逗号会把多项**用一个空格连起来**输出。注意逗号本身不显示，但逗号后面的空格会保留。

### 用法 2：控制分隔符与结尾

```python
print("A", "B", "C", sep="-")      # 用 - 连接各项
print("第一行", end="")             # end 默认是换行，改成空字符串就不换行
print("紧跟在后面")
```

**运行结果：**

```text
A-B-C
第一行紧跟在后面
```

| 参数 | 作用 | 默认值 |
|---|---|---|
| `sep` | 各项之间的分隔符 | 一个空格 `" "` |
| `end` | 输出后追加的字符 | 换行 `"\n"` |

### 用法 3：格式化字符串（f-string，推荐）

在字符串前加一个 `f`，用 `{}` 直接把变量嵌进文字里：

```python
length = 8
width = 5
area = length * width
print(f"长 {length}，宽 {width}，面积 {area}")
```

**运行结果：**

```text
长 8，宽 5，面积 40
```

!!! tip "为什么推荐 f-string"
    它把变量**直接写在句子里**，不用一堆逗号和拼接，读起来最接近自然语言。
    ```python
    # 三种写法对比，效果类似
    print("面积是", area)              # 逗号法，简单但夹杂空格
    print("面积是" + str(area))        # 拼接法，必须转换类型
    print(f"面积是 {area}")            # f-string，最清晰 ✅
    ```

## 二、输入：`input()`

`input()` 让程序**停下来等用户输入**，用户按回车后，程序继续执行。

```python
name = input("请输入你的名字：")
print("你好，", name)
```

**运行过程：**

```text
请输入你的名字：小明      ← 用户输入"小明"并按回车
你好， 小明
```

!!! danger "最重要的一条：`input()` 拿到的永远是字符串！"
    这几乎是所有初学者的第一个大坑：

    ```python
    a = input("请输入一个数字：")   # 用户输入 5
    print(a + 1)                    # ❌ 报错！
    ```

    报错信息：

    ```text
    TypeError: can only concatenate str (not "int") to str
    ```

    **原因**：用户输入的 `5` 被当成了**文字** `"5"`，文字不能和数字相加。
    **解决办法**：用 `int()` 或 `float()` 转换类型。

## 三、类型转换：把"文字"变成"数字"

| 函数 | 作用 | 示例 | 结果 |
|---|---|---|---|
| `int()` | 转成整数 | `int("5")` | `5` |
| `float()` | 转成浮点数 | `float("5")` | `5.0` |
| `str()` | 转成字符串 | `str(5)` | `"5"` |

**正确写法：**

```python
a = int(input("请输入一个数字："))    # 一边输入，一边转成整数
print(a + 1)
```

用户输入 `5` 时，输出：

```text
6
```

### 转换失败会怎样？

```python
int("abc")     # ❌ ValueError: invalid literal for int() with base 10: 'abc'
```

**原因**：`"abc"` 根本不是一个数字，无法转成整数。
所以要提醒用户**按格式输入**，或者用第 4 章的条件判断做"输入检查"。

## 四、代码实践：可以交互的面积计算器

把输入、转换、输出串起来：

```python title="area_calculator.py" linenums="1"
# 可交互的长方形面积计算器
print("=== 长方形面积计算器 ===")

length = float(input("请输入长："))
width = float(input("请输入宽："))

area = length * width

print(f"长 {length}，宽 {width}")
print(f"面积是 {area}")
```

**运行示例：**

```text
=== 长方形面积计算器 ===
请输入长：8
请输入宽：5
长 8.0，宽 5.0
面积是 40.0
```

!!! info "为什么用 `float()` 而不是 `int()`？"
    因为长和宽可能是小数（比如 3.5 米）。`float()` 能同时接受 `8` 和 `3.5`；
    而 `int()` 遇到 `3.5` 会报错。**当数据可能有小数时，用 `float()` 更稳妥。**

## 五、案例分析：把秒数换算成"时:分:秒"

> **问题**：用户输入一个整数（总秒数），输出它对应的小时、分钟、秒。
> 例如输入 `3725`，应输出 `1 小时 2 分 5 秒`。

**分析：**

| 环节 | 内容 |
|---|---|
| 输入 | 总秒数 `total` |
| 处理 | 小时 = 总秒数 // 3600；剩余 = 总秒数 % 3600；分钟 = 剩余 // 60；秒 = 剩余 % 60 |
| 输出 | 格式化输出三个数字 |

**代码实现：**

```python title="time_convert.py" linenums="1"
total = int(input("请输入总秒数："))

hours = total // 3600          # 1 小时 = 3600 秒，整除得小时数
remain = total % 3600          # 剩下的秒数
minutes = remain // 60         # 1 分钟 = 60 秒
seconds = remain % 60

print(f"{total} 秒 = {hours} 小时 {minutes} 分 {seconds} 秒")
```

**运行结果（输入 3725）：**

```text
3725 秒 = 1 小时 2 分 5 秒
```

!!! success "这个案例用到了什么"
    - `int(input(...))`：读入并转换成整数；
    - `//` 整除和 `%` 取余：**这两个运算符在竞赛题里出现频率极高**；
    - `f-string`：把结果拼成一句通顺的话。

    **自己动手改一改**：如果输入 `3661`，输出是什么？（答案：1 小时 1 分 1 秒）

## 本章小结

!!! abstract "第 3 章 小结"
    **1. 变量是贴了名字的盒子。** `=` 是赋值（从右往左），不是数学的"等于"；
    数学的等于在 Python 里是 `==`。

    **2. 命名要见名知义。** 只能由字母、数字、下划线组成，不能数字开头，区分大小写，
    不能用保留字。本教材统一用 `total_price` 这种小写下划线风格。

    **3. 三种基本类型。** `int`（整数）、`float`（小数）、`str`（字符串）。
    **`13` 和 `"13"` 完全不同**，引号是字符串的标志。

    **4. 除法要分清。** `/` 结果是小数，`//` 是整除，`%` 是取余。
    `//` 和 `%` 是竞赛高频运算符。

    **5. `input()` 永远返回字符串。** 想参与数学运算，必须用 `int()` 或 `float()` 转换。
    这是初学者第一大坑。

    **6. 输出推荐用 f-string。** `print(f"面积是 {area}")` 最清晰。

!!! question "练习 3（改错）"
    下面程序想输出"两数之积"，但运行报错。请找出错误并改正。

    ```python
    a = input("第一个数：")
    b = input("第二个数：")
    print("积是", a * b)
    ```

    ??? success "参考答案与评价要点"
        **错误**：`a`、`b` 都是字符串，字符串 `*` 数字虽然不报错，但含义是"重复"，
        例如 `"3" * "5"` 会直接报错（两个字符串不能相乘）。

        **正确改法**：
        ```python
        a = int(input("第一个数："))
        b = int(input("第二个数："))
        print("积是", a * b)
        ```

        评价要点：能指出"必须转成数字类型"即得满分（100 分）。
