# 第 3 章 变量、数据类型与输入输出

!!! abstract "本章导学"
    第 2 章我们画好了"流水线"，但还没有真正的"零件"。这一章开始，你要正式学 Python 语法了。
    它是全书的**第一块地基**：变量是"盒子"，数据类型是"盒子里装什么"，
    输入输出是"程序与用户的对话"。这三样东西，后面每一章都会用到。

## 学习目标

学完本章，你应当能够：

1. **定义并使用** 变量，理解"赋值"是从右往左进行的；
2. **区分** 三种基本数据类型：整数 `int`、浮点数 `float`、字符串 `str`；
3. **使用** `input()` 读取用户输入、用 `print()` 输出结果；
4. **进行** 类型转换（`int()`、`float()`、`str()`），并解释为什么必须转换。

## 一个贯穿全书的例子

本章及后续章节会用同一个例子来演示新知识：**"计算长方形的面积"**。

| 环节 | 内容 |
|---|---|
| 输入 | 长、宽 |
| 处理 | 面积 = 长 × 宽 |
| 输出 | 面积值 |

第 2 章你只会"想"，从这一章起，你会一步步写出真正能运行、能接收用户输入的程序。

---

!!! tip "学习方法提醒"
    本章的代码**务必亲手敲**。变量名可以改成你自己的习惯，但请保持"见名知义"——
    `length` 比 `a` 好，`area` 比 `x` 好。这个小习惯会让你的代码越写越清楚。
