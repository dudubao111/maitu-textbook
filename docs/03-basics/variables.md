# 3.1 变量与数据类型

## 一、变量：给数据贴上名字的盒子

**变量（Variable）就是计算机内存里一个"贴了名字的盒子"，用来存放数据。**

```python
age = 13
```

这一行的意思是：**准备一个叫 `age` 的盒子，把数字 `13` 放进去。**

你可能会问：`13` 存在哪里？什么时候取出来？看下面的例子：

```python
price = 12.5
print(price)     # 从盒子里取出内容并打印
price = 15.0     # 往同一个盒子里放入新内容（旧的被覆盖）
print(price)
```

**运行结果：**

```text
12.5
15.0
```

!!! warning "变量名只是标签，不是容器"
    更准确地说，变量是**贴在数据上的名字**。当写 `price = 15.0` 时，
    相当于把 `price` 这个标签从 `12.5` 撕下来，贴到了 `15.0` 上。
    原来的 `12.5` 如果没人再用它，就会被系统回收。

### 赋值的方向：从右往左

这是初学者最容易搞错的地方：

```python
x = 5      # ✅ 正确：把 5 放进 x
5 = x      # ❌ 报错：5 不是一个盒子，不能往里放东西
```

**记住：`=` 不读作"等于"，而读作"赋值"——把右边的值放进左边的变量里。**
数学里的"等于"在 Python 里写作 `==`（第 4 章讲）。

### 变量命名规则

| 规则 | 正确示例 | 错误示例 | 说明 |
|---|---|---|---|
| 只能由字母、数字、下划线组成 | `score1` | `score-1` | `-` 是减号 |
| 不能以数字开头 | `num2` | `2num` | 数字开头会被当成数字 |
| 区分大小写 | `Score` 与 `score` 是两个变量 | — | 注意统一大小写 |
| 不能用 Python 保留字 | `total` | `if`、`for`、`print` | 这些词有特殊含义 |
| 建议见名知义 | `total_price` | `a1` | 方便自己和同学读代码 |

!!! tip "两种常见的命名风格"
    - **小写下划线**（Python 社区主流）：`total_price`、`student_name`
    - **小驼峰**（其他语言常见）：`totalPrice`、`studentName`

    本教材统一使用**小写下划线**风格。选一种并坚持，别混着用。

## 二、三种基本数据类型

盒子有了名字，但**盒子里装的东西可以完全不同**。Python 中最常用的三种类型是：

| 类型 | 名称 | 关键字 | 例子 | 用途 |
|---|---|---|---|---|
| 整数 | `int` | Integer | `13`、`-5`、`0`、`2026` | 人数、个数、年龄 |
| 浮点数 | `float` | Float | `12.5`、`3.14`、`-0.5` | 价格、成绩、长度 |
| 字符串 | `str` | String | `"你好"`、`"Python"`、`'86'` | 姓名、科目、一段文字 |

**怎么知道一个变量是什么类型？** 用 `type()` 函数：

```python
print(type(13))        # <class 'int'>
print(type(12.5))      # <class 'float'>
print(type("你好"))    # <class 'str'>
```

**运行结果：**

```text
<class 'int'>
<class 'float'>
<class 'str'>
```

!!! danger "最容易踩的坑：`13` 和 `"13"` 不是一回事"
    ```python
    print(13 + 1)      # 输出 14     ← 数字相加，做数学运算
    print("13" + "1")  # 输出 131    ← 文字拼接，把两个字符串接在一起
    ```
    引号是"字符串"的标志。**加了引号就是文字，不加引号才是数字。**

## 三、数字的算术运算

Python 的数字运算符号大部分和数学一样，但有两个容易忽略的：

| 运算符 | 名称 | 示例 | 结果 | 说明 |
|---|---|---|---|---|
| `+` | 加 | `7 + 2` | `9` | |
| `-` | 减 | `7 - 2` | `5` | |
| `*` | 乘 | `7 * 2` | `14` | 注意用 `*` 不用 `×` |
| `/` | 除 | `7 / 2` | `3.5` | **结果一定是小数** |
| `//` | 整除 | `7 // 2` | `3` | 只取整数部分，舍去小数 |
| `%` | 取余 | `7 % 2` | `1` | 求余数，判断奇偶常用 |
| `**` | 幂 | `7 ** 2` | `49` | 7 的 2 次方 |

!!! info "为什么 `7 / 2` 得到 3.5 而不是 3？"
    Python 中 `/` 是"真除法"，**结果永远是浮点数**，哪怕能除尽：
    ```python
    print(6 / 2)     # 输出 3.0（注意有个 .0）
    print(6 // 2)    # 输出 3（整除，得到整数）
    ```
    在竞赛题里，题目要求"输出整数"时要用 `//` 或 `int()`，
    要求"保留小数"时要用 `/`。这个区别必须分清。

## 四、代码实践：计算长方形面积

把本节知识串起来，写一个完整程序：

```python title="rectangle_area.py" linenums="1"
# 计算长方形面积（先用固定的长和宽）
length = 8       # 长
width = 5        # 宽

area = length * width     # 处理：相乘

print("长方形的长是", length)
print("长方形的宽是", width)
print("面积是", area)
```

**运行结果：**

```text
长方形的长是 8
长方形的宽是 5
面积是 40
```

!!! note "`print` 可以一次输出多项"
    `print("面积是", area)` 中的逗号会让各项**用空格隔开**依次输出。
    这是 Python 里最常用的输出方式，第 3.2 节会详细讲。

## 五、案例分析：两个数交换

> **问题**：变量 `a = 3`、`b = 8`，如何交换它们的值，使 `a = 8`、`b = 3`？

**思路分解**（第 2 章学过的分解思想）：

```text
① 先把 a 的值暂存到临时变量 temp
② 把 b 的值赋给 a
③ 把 temp 的值赋给 b
```

**代码实现：**

```python title="swap.py" linenums="1"
a = 3
b = 8
print("交换前： a =", a, " b =", b)

temp = a     # ① 把 a 的值先存起来
a = b        # ② b 的值给 a
b = temp     # ③ 暂存的原 a 值给 b

print("交换后： a =", a, " b =", b)
```

**运行结果：**

```text
交换前： a = 3  b = 8
交换后： a = 8  b = 3
```

!!! question "为什么不能直接 `a = b; b = a`？"
    如果先执行 `a = b`，`a` 就变成了 `8`，**原来的 `3` 就丢了**；
    再执行 `b = a`，`b` 也只是拿到 `8`。最后两个变量都是 `8`。
    临时变量 `temp` 的作用就是"先备份，再覆盖"。这个例子很好体现了**算法需要顺序正确**。

!!! tip "Python 的快捷写法"
    Python 支持一行交换，效果和上面完全一样：
    ```python
    a, b = b, a
    ```
    这是 Python 的特性，不是所有语言都有。初学阶段建议先用 `temp` 写清楚逻辑。
