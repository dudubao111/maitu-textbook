# 第 6 章 函数与模块化

!!! abstract "本章导学"
    前五章你写的程序都是"一路往下写"。但当代码变长，你会遇到两个问题：
    ① 同样的逻辑写了好几遍；② 程序太长，看不懂了。这一章教你**函数**——
    把一段代码"打包"起来，起个名字，需要时调用。它是从"会写代码"到"会写好代码"的分水岭。

## 学习目标

学完本章，你应当能够：

1. **定义和调用** 函数，理解"参数"与"返回值"的作用；
2. **判断** 什么时候应该把代码抽成一个函数；
3. **使用** 默认参数和多个返回值；
4. **理解** 递归的思想，能写出阶乘、斐波那契等经典递归程序；
5. **说明** 递归必须满足的两个条件（终止条件 + 向终止条件靠近）。

## 一个"痛点"引出函数

第 4 章你写过一个"判断素数"的程序。现在如果**要判断 10 个数是不是素数**，你会怎么办？

=== "不用函数（复制粘贴 10 遍）"
    ```python
    n1 = int(input())
    is_prime = True
    for i in range(2, n1):
        if n1 % i == 0:
            is_prime = False
            break
    print(is_prime)

    n2 = int(input())
    is_prime = True
    for i in range(2, n2):
        if n2 % i == 0:
            is_prime = False
            break
    print(is_prime)
    # …… 还要再重复 8 次 😱
    ```

    **问题**：代码冗长、难改（要改逻辑得改 10 处）、容易出错。

=== "用函数（写一次，用十次）"
    ```python
    def is_prime(n):
        if n < 2:
            return False
        for i in range(2, n):
            if n % i == 0:
                return False
        return True

    for _ in range(10):
        num = int(input())
        print(is_prime(num))
    ```

    **优势**：逻辑只写一遍；想优化只改一处；主程序只有 3 行，一眼看懂。

**这就是函数的价值：一次编写，多次复用。**
