    3.2 输入输出与类型转换¶

    一、输出：print()¶

    print() 是最常用的输出函数，它有三种常见用法。

    用法 1：一次输出多项（用逗号隔开）¶

    name = "小明"
score = 92
print("姓名：", name, "，成绩：", score)

    运行结果：

    姓名： 小明 ，成绩： 92

    逗号会把多项用一个空格连起来输出。注意逗号本身不显示，但逗号后面的空格会保留。

    用法 2：控制分隔符与结尾¶

    print("A", "B", "C", sep="-")      # 用 - 连接各项
print("第一行", end="")             # end 默认是换行，改成空字符串就不换行
print("紧跟在后面")

    运行结果：

    A-B-C
第一行紧跟在后面
    参数 作用 默认值
    sep 各项之间的分隔符 一个空格 " "
    end 输出后追加的字符 换行 "\n"

    用法 3：格式化字符串（f-string，推荐）¶

    在字符串前加一个 f，用 {} 直接把变量嵌进文字里：

    length = 8
width = 5
area = length * width
print(f"长 {length}，宽 {width}，面积 {area}")

    运行结果：

    长 8，宽 5，面积 40

    为什么推荐 f-string

    它把变量直接写在句子里，不用一堆逗号和拼接，读起来最接近自然语言。 

    # 三种写法对比，效果类似
print("面积是", area)              # 逗号法，简单但夹杂空格
print("面积是" + str(area))        # 拼接法，必须转换类型
print(f"面积是 {area}")            # f-string，最清晰 ✅

    二、输入：input()¶

    input() 让程序停下来等用户输入，用户按回车后，程序继续执行。

    name = input("请输入你的名字：")
print("你好，", name)

    运行过程：

    请输入你的名字：小明      ← 用户输入"小明"并按回车
你好， 小明

    最重要的一条：input() 拿到的永远是字符串！

    这几乎是所有初学者的第一个大坑：

    a = input("请输入一个数字：")   # 用户输入 5
print(a + 1)                    # ❌ 报错！

    报错信息：

    TypeError: can only concatenate str (not "int") to str

    原因：用户输入的 5 被当成了文字 "5"，文字不能和数字相加。 解决办法：用 int() 或 float() 转换类型。

    三、类型转换：把"文字"变成"数字"¶

    函数 作用 示例 结果
    int() 转成整数 int("5") 5
    float() 转成浮点数 float("5") 5.0
    str() 转成字符串 str(5) "5"

    正确写法：

    a = int(input("请输入一个数字："))    # 一边输入，一边转成整数
print(a + 1)

    用户输入 5 时，输出：

    6

    转换失败会怎样？¶

    int("abc")     # ❌ ValueError: invalid literal for int() with base 10: 'abc'

    原因："abc" 根本不是一个数字，无法转成整数。 所以要提醒用户按格式输入，或者用第 4 章的条件判断做"输入检查"。

    四、代码实践：可以交互的面积计算器¶

    把输入、转换、输出串起来：

    area_calculator.py

    # 可交互的长方形面积计算器
print("=== 长方形面积计算器 ===")

length = float(input("请输入长："))
width = float(input("请输入宽："))

area = length * width

print(f"长 {length}，宽 {width}")
print(f"面积是 {area}")

    运行示例：

    === 长方形面积计算器 ===
请输入长：8
请输入宽：5
长 8.0，宽 5.0
面积是 40.0

    为什么用 float() 而不是 int()？

    因为长和宽可能是小数（比如 3.5 米）。float() 能同时接受 8 和 3.5； 而 int() 遇到 3.5 会报错。当数据可能有小数时，用 float() 更稳妥。

    五、案例分析：把秒数换算成"时:分:秒"¶

    问题：用户输入一个整数（总秒数），输出它对应的小时、分钟、秒。 例如输入 3725，应输出 1 小时 2 分 5 秒。

    分析：

    环节 内容
    输入 总秒数 total
    处理 小时 = 总秒数 // 3600；剩余 = 总秒数 % 3600；分钟 = 剩余 // 60；秒 = 剩余 % 60
    输出 格式化输出三个数字

    代码实现：

    time_convert.py
    1
2
3
4
5
6
7
8
    total = int(input("请输入总秒数："))

hours = total // 3600          # 1 小时 = 3600 秒，整除得小时数
remain = total % 3600          # 剩下的秒数
minutes = remain // 60         # 1 分钟 = 60 秒
seconds = remain % 60

print(f"{total} 秒 = {hours} 小时 {minutes} 分 {seconds} 秒")

    运行结果（输入 3725）：

    3725 秒 = 1 小时 2 分 5 秒

    这个案例用到了什么

    • int(input(...))：读入并转换成整数；
    • // 整除和 % 取余：这两个运算符在竞赛题里出现频率极高；
    • f-string：把结果拼成一句通顺的话。

    自己动手改一改：如果输入 3661，输出是什么？（答案：1 小时 1 分 1 秒）

    六、实践任务 3-1：BMI 计算器¶

    任务说明

    输入：身高（米，可能有小数）、体重（千克，可能有小数）——均由用户通过 input() 输入。 操作要求： 1. 用 float() 转换两个输入； 2. 按公式 BMI = 体重 ÷ 身高² 计算； 3. 用 f-string 输出结果，保留合理表述。 预期结果：输入身高 1.6、体重 50，输出约为 19.53125。 评价标准： - 输入输出流程正确、能运行（40 分） - 公式正确（注意身高要平方，写 height ** 2）（40 分） - 输出文字清晰、有单位（20 分）

    七、实践任务 3-2：修复下面的代码¶

    任务说明

    背景：下面这段代码想计算"两个整数的和"，但运行会报错。 输入：代码（见下）。 操作要求：找出错误原因，修改后使程序能正确输出两数之和。 预期结果：输入 3 和 5，程序输出 8。

    a = input("请输入第一个数：")
b = input("请输入第二个数：")
print(a + b)

    评价标准： - 能指出"input() 得到的是字符串"这一根因（40 分） - 修改后程序能正确运行（40 分） - 能说明为什么 "3" + "5" 得到的是 "35" 而不是 8（20 分）

    本章小结¶

    第 3 章 小结

    1. 变量是贴了名字的盒子。 = 是赋值（从右往左），不是数学的"等于"； 数学的等于在 Python 里是 ==。

    2. 命名要见名知义。 只能由字母、数字、下划线组成，不能数字开头，区分大小写， 不能用保留字。本教材统一用 total_price 这种小写下划线风格。

    3. 三种基本类型。 int（整数）、float（小数）、str（字符串）。 13 和 "13" 完全不同，引号是字符串的标志。

    4. 除法要分清。 / 结果是小数，// 是整除，% 是取余。 // 和 % 是竞赛高频运算符。

    5. input() 永远返回字符串。 想参与数学运算，必须用 int() 或 float() 转换。 这是初学者第一大坑。

    6. 输出推荐用 f-string。 print(f"面积是 {area}") 最清晰。

    练习与参考¶

    练习 1（判断）

    判断下列各变量的类型，并说明理由。

    1. a = 100
    2. b = "100"
    3. c = 100.0
    参考答案与评价要点
    1. int（整数，无引号无小数点）　2. str（有引号，是文字）　3. float（有小数点）

    评价要点：三题全对得 100 分。若把 3 答成 int，说明还没理解小数点即浮点数，扣 30 分。

    练习 2（计算）

    写出下列各式的结果：

    1. 17 // 5
    2. 17 % 5
    3. 17 / 5
    参考答案与评价要点
    1. 3　2. 2　3. 3.4

    评价要点：第 3 题若答 3，说明混淆了 / 与 //，需回看 3.1 节。

    练习 3（改错）

    下面程序想输出"两数之积"，但运行报错。请找出错误并改正。

    a = input("第一个数：")
b = input("第二个数：")
print("积是", a * b)
    参考答案与评价要点

    错误：a、b 都是字符串，字符串 * 数字虽然不报错，但含义是"重复"， 例如 "3" * "5" 会直接报错（两个字符串不能相乘）。

    正确改法： 

    a = int(input("第一个数："))
b = int(input("第二个数："))
print("积是", a * b)

    评价要点：能指出"必须转成数字类型"即得满分（100 分）。

    练习 4（操作）

    编写程序：输入圆的半径 r（可能是小数），输出圆的周长和面积。 圆周率请使用 3.14159。（周长 = 2 × π × r，面积 = π × r²）

    参考答案与评价要点 
    PI = 3.14159
r = float(input("请输入半径："))
circumference = 2 * PI * r
area = PI * r ** 2
print(f"周长是 {circumference}")
print(f"面积是 {area}")

    评价要点：能运行且结果正确（60 分）；正确使用 float()（20 分）； 面积公式正确使用 r ** 2（20 分）。

    练习 5（思考）

    小明写了一段代码 age = input("你几岁？")，然后想计算 age + 1， 结果报错。请解释原因，并给出两种不同的修改方案。

    参考答案与评价要点

    原因：input() 返回字符串，"13" + 1 类型不匹配。

    方案一：输入时就转换 —— age = int(input("你几岁？")) 方案二：先输入后转换 —— age = input("你几岁？"); age = int(age)

    评价要点：能准确说出根因（50 分）；给出两种可行方案（各 25 分）。
