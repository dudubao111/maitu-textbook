    码途 · 中小学信息科技竞赛数字教材¶

    从计算思维到算法实践 —— 一本写给中小学竞赛初学者的 Python 数字教材。

    本教材面向零基础或刚起步的参赛学生，用"看得懂的讲解 + 跑得动的代码 + 做得到的任务"， 把信息科技竞赛需要的核心知识与算法思想拆成 8 章，从认识比赛一路走到独立完成一道竞赛题。

    适用学段：初中为主 · 小学高年级可跟读前 3 章 建议课时：32 课时 语言：Python 关联：信息科技新课标 · 信息素养类白名单赛事

    这本教材写给谁？¶

    项目 说明
    目标读者 初中学生为主，零基础或刚接触编程；小学高年级学生可跟读第 1—3 章。也适合信息技术教师作为竞赛课教材或社团讲义
    前置知识 会使用电脑基本操作即可，不需要任何编程基础，不需要提前学数学竞赛内容
    学习方式 边读边敲代码。每节都有可以在本地或在线环境直接运行的完整程序，改一改、跑一跑，比只看更有效
    学完之后 能读懂竞赛题、能用 Python 写出正确解法、能自己调试错误、了解参赛与提交的基本流程

    不同学段怎么用：难度是分层的

    章节 难度 适合谁
    第 1—3 章 入门 小学高年级及以上，只要有基本的打字和文件操作能力
    第 4—6 章 进阶 建议初中及以上。嵌套循环与递归需要一定的抽象思维能力
    第 7—8 章 竞赛向 建议初中高年级及以上，或已完整学完前 6 章的学生

    小学高年级的同学先把前 3 章学扎实（认识竞赛、计算思维、变量与输入输出）， 这已经能覆盖新课标中信息科技的大部分基础要求；第 4 章之后再按自己的节奏推进，不要硬赶。

    给零基础同学的提醒

    看不懂是正常的，跳过继续往后读也可以。第 1—3 章是地基，慢一点没关系； 第 4 章开始是竞赛真正的高频考点，前面的内容会在后面反复用到。 如果某段代码报错，先照着"实践任务"里的提示逐条检查，多数问题都能自己解决。

    关于语言选择：为什么是 Python？

    这本教材用 Python 教学，原因有三：一是 Python 语法接近自然语言，零基础学生上手最快； 二是中小学信息科技新课标把 Python 作为主要教学语言；三是信息素养类、人工智能类赛事普遍支持 Python。 但要如实说明：信息学奥赛体系中的 CSP-J/S 与 NOI 只接受 C++ 提交，不能用 Python。 因此本教材的定位是"用 Python 学会算法思维与编程方法"，学完第 7 章后， 可以按 第 8 章 · 提交规范与实战流程 的指引平滑迁移到 C++ 去参加 CSP-J/S。 现在就把 Python 当"学骑车的辅助轮"，不要指望用 Python 直接打信息学奥赛。

    学习目标¶

    学完本教材，你应当能够：

    1. 说清楚 常见中小学信息科技竞赛有哪些、面向哪个学段、需要什么准备；
    2. 用计算思维 把一个生活问题拆成"输入 — 处理 — 输出"三步，并写成算法步骤；
    3. 熟练使用 Python 的变量、数据类型、输入输出、分支、循环、列表与字符串；
    4. 会写函数，能把重复代码打包复用，并理解递归的基本思想；
    5. 掌握四类基础算法：枚举、查找、排序、递推，并能判断该用哪一种；
    6. 独立完成 一道竞赛题的读题、建模、编码、调试与提交全过程。

    教材章节¶

    第 1 章 走进信息科技竞赛 认识常见竞赛、了解参赛要求，搭好编程环境，找到属于自己的学习地图。

    第 2 章 计算思维与问题分解 学会像计算机一样思考：分解、抽象、建模，把大问题变成小步骤。

    第 3 章 变量、数据类型与输入输出 程序的"存储"与"对话"：变量、整数浮点字符串、input 与 print。

    第 4 章 流程控制 让程序会判断、会重复：if 分支与 for / while 循环，竞赛高频考点。

    第 5 章 列表与字符串处理 批量管理数据与处理文本，几乎所有竞赛题都离不开它们。

    第 6 章 函数与模块化 把代码打包成函数，理解参数与返回值，迈入递归的世界。

    第 7 章 基础算法入门 枚举、查找、排序、递推与贪心，用四种武器解决大部分入门题。

    第 8 章 竞赛实战与提交规范 读题建模、调试排错、提交规范与实战流程，把知识变成分数。

    学习路径¶

    1 打地基 第 1—3 章：认识竞赛、建立计算思维、学会变量与输入输出。
    2 学语法 第 4—6 章：流程控制、列表字符串、函数，这是能写程序的标志。
    3 练算法 第 7 章：枚举、查找、排序、递推，开始真正面对竞赛考点。
    4 上战场 第 8 章 + 真题练习：读题、编码、调试、提交，形成完整闭环。

    怎么用这本教材¶

    三种推荐用法

    • 自学路线：从第 1 章顺序读，每节的"实践任务"必须动手做一遍再往下走。
    • 上课路线：教师可用每章的"学习目标"当课时目标，"案例分析"当课堂范例，课后留"练习与参考"。
    • 冲刺路线：基础较好的同学可直接从第 4 章开始，把第 7 章的每种算法都手写一遍。

    关于代码的重要提醒

    教材中所有标注为可运行的代码，都是完整程序，复制到 Python 环境里可以直接运行。 不含"伪代码"。如果你看到 # ... 省略号，那只是为了节省篇幅，请对照上下文补全后再运行。
