    附录 A · 术语表¶

    本表收录全书出现的关键术语。按类别分组，方便查阅。

    一、竞赛与学习¶

    术语 英文 解释
    教育部白名单 — 教育部公布的《面向中小学生的全国性竞赛活动名单》。入围赛事须做到"零收费、不与升学挂钩、每学年不超过 1 次"。
    CSP-J/S CCF CSP-J/S 中国计算机学会主办的"非专业级软件能力认证"，分入门级（J）与提高级（S）两组，只接受 C++ 提交。
    NOI National Olympiad in Informatics 全国中学生信息学奥林匹克竞赛，面向高中，是信息学奥赛的最高级别赛事。
    计算思维 Computational Thinking 用计算机能理解的方式把问题想清楚的能力，包含分解、模式识别、抽象、算法四个要素。
    信息素养 Information Literacy 获取、评估、利用信息的能力。信息素养类赛事通常支持多种编程语言。

    二、Python 基础¶

    术语 英文 解释
    变量 Variable 给数据起的"名字"，通过赋值 = 把值绑定到名字上。
    赋值 Assignment = 运算，把右边的值赋给左边的变量，方向是从右往左。
    整数 int 不带小数点的数，如 13、-5。
    浮点数 float 带小数点的数，如 3.14、12.5。浮点运算可能有微小误差。
    字符串 str 用引号包围的文本，如 "你好"、'abc'。不可修改。
    布尔值 bool 只有 True 和 False 两个值，条件判断的结果类型。
    类型转换 Type Conversion 用 int()、float()、str() 把一种类型转成另一种。
    注释 Comment # 开头的文字，仅供人阅读，计算机不执行。
    缩进 Indentation 行首的空格。Python 用它表示代码块的从属关系，是语法的一部分。
    局部变量 Local Variable 在函数内部定义的变量，只在函数内有效。

    三、流程控制¶

    术语 英文 解释
    分支结构 Branch 用 if / elif / else 让程序根据条件选择执行路径。
    循环结构 Loop 用 for 或 while 让代码重复执行。
    左闭右开 Half-open Interval range(1, 5) 生成 1,2,3,4，包含起点、不包含终点。切片同理。
    死循环 Infinite Loop 循环条件永远为真，程序无法结束（用 Ctrl + C 停止）。
    break — 立即跳出整个循环。
    continue — 跳过本次循环，直接进入下一次。
    遍历 Iteration 依次访问序列中的每个元素。

    四、数据结构¶

    术语 英文 解释
    列表 list 有序的数据集合，用 [] 创建，索引从 0 开始。
    索引 Index 元素在序列中的位置编号，从 0 开始；负数表示从末尾数起。
    切片 Slice lst[1:4] 一次取出序列的一段，规则同样是左闭右开。
    元组 tuple 不可修改的有序集合，用 () 创建，常用于"返回多个值"。
    字典 dict 键值对集合，用 {} 创建，如 {"a": 1}，适合做"映射"和"计数"。

    五、函数¶

    术语 英文 解释
    函数 Function 一段有名字、可反复调用的代码，用 def 定义。
    参数 Parameter 函数从外界接收数据的"入口"。
    返回值 Return Value 函数用 return 交回给调用者的结果。没有 return 则返回 None。
    None — Python 中表示"什么都没有"的特殊值。
    默认参数 Default Parameter 定义时给了默认值的参数，调用时可以省略。
    递归 Recursion 函数调用自身。必须具备终止条件和向终止条件靠近的递推关系。
    调用栈 Call Stack 程序记录函数调用层次的结构，遵循"后进先出"。

    六、算法¶

    术语 英文 解释
    算法 Algorithm 解决问题的有限步骤序列。
    枚举法 Enumeration 逐一尝试所有可能，从中找出满足条件的答案。
    剪枝 Pruning 提前排除明显不可能的选项，缩小枚举范围以提速。
    顺序查找 Linear Search 从头到尾逐个比较，复杂度 O(n)，不要求数据有序。
    二分查找 Binary Search 每次砍掉一半搜索范围，复杂度 O(log n)，要求数据有序。
    冒泡排序 Bubble Sort 反复比较交换相邻元素，每轮把最大值"冒"到末尾。
    选择排序 Selection Sort 每轮从未排序部分选出最小值，放到已排序部分末尾。
    递推 Recurrence 根据前几项按固定规律推出后续项，通常用循环实现。
    贪心 Greedy 每一步都选当前最优，不保证全局最优，需要能证明正确性。
    时间复杂度 Time Complexity 衡量运算次数随数据量增长的快慢，如 O(1)、O(n)、O(n²)、O(log n)。

    七、竞赛实战¶

    术语 英文 解释
    WA Wrong Answer 答案错误。
    TLE Time Limit Exceeded 超出时间限制（超时）。
    RE Runtime Error 运行时错误，如数组越界、除零、递归过深。
    PE Presentation Error 输出格式错误。
    CE Compile Error 编译错误（主要出现在 C++ 中）。
    样例 Sample 题目给出的输入输出示例，用于验证理解是否正确。
    边界情况 Edge Case 极端输入，如 n = 1、全负数、全相同。必须测试。
