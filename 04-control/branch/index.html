    4.1 分支结构：让程序会选择¶

    一、为什么需要分支¶

    看一个最简单的需求：输入一个分数，判断是否及格。

    第 3 章的知识只能这么写（而且写不出来）：

    score = int(input("请输入分数："))
# 怎么办？分数 >= 60 时要输出"及格"，否则输出"不及格"……写不下去了

    if 就是答案。

    二、if 的基本写法¶

    score = int(input("请输入分数："))

if score >= 60:
    print("及格")

    运行结果（输入 75）：

    及格

    拆解这三行：

    部分 内容 说明
    关键字 if 表示"如果"
    条件 score >= 60 一个能判断真假（True / False）的表达式
    冒号 : 不能漏，表示"接下来是满足条件时要做的事"
    缩进 4 个空格 表示这几行属于 if，这是 Python 最独特的地方

    缩进是语法，不是排版

    Python 用缩进来表示从属关系。下面两段代码完全不同：

    # 写法 A：只有 print 属于 if
if score >= 60:
    print("及格")
print("程序结束")

# 写法 B：两行都属于 if
if score >= 60:
    print("及格")
    print("程序结束")

    缩进错了，程序的逻辑就错了。 请统一用 4 个空格，不要用 Tab 和空格混着来。

    三、if ... else：两条路¶

    score = int(input("请输入分数："))

if score >= 60:
    print("及格")
else:
    print("不及格")

    else 表示"否则"，它没有条件，紧跟在 if 的代码块之后。

    四、if ... elif ... else：多条路¶

    成绩等级有多档，这时用 elif（else if 的缩写）：

    score = int(input("请输入分数："))

if score >= 90:
    grade = "A"
elif score >= 80:
    grade = "B"
elif score >= 70:
    grade = "C"
elif score >= 60:
    grade = "D"
else:
    grade = "E"

print(f"成绩等级：{grade}")

    运行结果：

    输入 85 → 成绩等级：B
输入 59 → 成绩等级：E

    顺序至关重要

    elif 是从上往下依次判断，遇到第一个为真的分支就执行并跳过其余分支。

    如果把顺序写反：

    if score >= 60:
    grade = "D"
elif score >= 90:      # ❌ 永远轮不到这里
    grade = "A"

    那么输入 95 会得到 "D"——因为 95 >= 60 已经为真，后面的 elif 根本不会被检查。 条件严格的要写在前面。 这是考试和竞赛的高频陷阱。

    五、比较运算符与逻辑运算符¶

    比较运算符（结果是 True 或 False）¶

    运算符 含义 示例 结果
    == 等于 5 == 5 True
    != 不等于 5 != 3 True
    > 大于 5 > 3 True
    < 小于 5 < 3 False
    >= 大于等于 5 >= 5 True
    <= 小于等于 5 <= 3 False

    最常见的错误：把 == 写成 =

    • if score = 60: ❌ 语法错误（这是赋值）
    • if score == 60: ✅ 比较是否相等

    记忆口诀：一个等号是"赋值"，两个等号才是"等于"。

    逻辑运算符¶

    运算符 含义 示例 结果
    and 两个都真才真 60 <= s and s <= 100 判断是否在 [60,100] 区间
    or 一个真就真 s < 0 or s > 100 判断是否越界
    not 取反 not (s >= 60) 等价于 s < 60

    Python 还支持连续比较（这是它的贴心设计）：

    if 60 <= score <= 100:     # 等价于 60 <= score and score <= 100
    print("分数合法")

    六、代码实践：判断闰年¶

    问题：输入一个年份，判断它是不是闰年。 规则：能被 4 整除但不能被 100 整除的是闰年；能被 400 整除的也是闰年。

    leap_year.py
    1
2
3
4
5
6
    year = int(input("请输入年份："))

if (year % 4 == 0 and year % 100 != 0) or (year % 400 == 0):
    print(f"{year} 年是闰年")
else:
    print(f"{year} 年不是闰年")

    运行结果：

    输入 2024 → 2024 年是闰年
输入 2100 → 2100 年不是闰年
输入 2000 → 2000 年是闰年

    为什么 2100 不是闰年？

    2100 能被 4 整除，也能被 100 整除，但不能被 400 整除， 所以它不满足"能被 4 整除且不能被 100 整除"，也不满足"能被 400 整除"。 这就是条件里必须写 year % 100 != 0 的原因。

    七、案例分析：快递运费计算¶

    问题：某快递公司计费规则： 重量不超过 1 千克收费 10 元；超过 1 千克的部分每千克加收 5 元（不足 1 千克按 1 千克算）。 请计算运费。

    分析：

    环节 内容
    输入 重量（千克，可能是小数）
    处理 若 ≤ 1，运费 = 10；否则，多出的重量向上取整后再 × 5
    输出 运费

    代码实现：

    express_fee.py

    weight = float(input("请输入重量（千克）："))

if weight <= 1:
    fee = 10
else:
    extra = weight - 1
    # 不足 1 千克按 1 千克算，需要向上取整
    if extra != int(extra):
        extra = int(extra) + 1
    fee = 10 + extra * 5

print(f"运费是 {fee} 元")

    运行结果：

    输入 1    → 运费是 10 元
输入 2.3  → 运费是 20 元    （多出 1.3 千克，按 2 千克算，10 + 2×5）
输入 3    → 运费是 20 元    （多出 2 千克，10 + 2×5）

    嵌套 if：if 里面还能有 if

    上面 else 块里又出现了一个 if，这叫嵌套。 写嵌套时缩进要格外小心，建议每进一层多缩进 4 个空格。

    另一种更简洁的写法（第 6 章学完函数后会更自然）： 

    import math
extra = math.ceil(weight - 1)   # math.ceil 表示向上取整
fee = 10 + extra * 5
    本阶段先用嵌套 if 把逻辑写清楚。

    八、实践任务 4-1：三角形判定¶

    任务说明

    输入：三个整数 a、b、c，代表三条边长。 操作要求：判断这三条边能否构成三角形。 （提示：三角形的充要条件是任意两边之和大于第三边） 预期结果： - 输入 3 4 5 → 输出 可以构成三角形 - 输入 1 2 10 → 输出 不能构成三角形

    评价标准： - 能写出正确的三个条件并用 and 连接（50 分） - 程序可运行、结果正确（40 分） - 有必要的注释（10 分）

    九、实践任务 4-2：找出三个数中的最大值¶

    任务说明

    输入：三个整数。 操作要求：不使用 Python 内置的 max() 函数，用分支结构找出最大值。 预期结果：输入 12 -5 30，输出 最大值是 30。 评价标准： - 能用 if/elif/else 正确比较（60 分） - 能覆盖"三个数相等"等边界情况（20 分） - 能说明为什么不能只用两个 if（20 分）
